FEML — release installation and validation notes
================================================

Installation
------------
Use the standard real-valued Firedrake release with ML model-parameter adjoints
(model_parameters=True), its default PETSc configuration, PyTorch, and PySR 1.5.10.
Follow README.md; no component checkouts or source patches are required.
PySR 1.5.10 is retained because example 06 uses its 1.x interface. Julia is managed
by PySR. PyTorch 2.4.1 was used for validation. The standard instructions let pip
select a PyTorch version compatible with your Python installation.

Validation record, 25 September 2026
-----------------------------------
All six scripts completed at full paper settings on Linux ARM64 with Python 3.12.3
and PyTorch 2.4.1. Their source is unchanged from those runs. The validation used
Firedrake commit 476c5d23442cd9085c3a2bf78d2c997a8c59c9bc, based on main commit
a0af36be23723a4e134874c62e8b564d854ce2a2, before release publication. These hashes
record the validation environment; they are not installation requirements.

The full symbolic search used PySR 1.5.10 and the original Julia 1.12.5 environment.
It reproduced the reference expression and saved scores exactly. Julia 1.12.5 is
outside PySR 1.5.10's declared version range; that archived combination is not
required for the standard setup. PySR's automatically resolved Julia 1.11.9 also
passed a short search, but the full paper search was not repeated with that runtime.
A different Julia/package resolution can select a different symbolic expression.

Saved numerical outputs closely matched the references. Finite-difference gradient
checks met a relative-error threshold of 1e-3 for load control, shear hardening and
thermal training. Displacement and shear-damage gradients showed sensitivity to
the original nonlinear solver tolerances; stricter diagnostic solves improved
agreement. The paper's solver settings were retained in the scripts.

The original custom-stack versions and patches are preserved in the v1.0.0 archive:
https://doi.org/10.5281/zenodo.21251672
